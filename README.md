# SKIDUSH

Tu sistema de contenido con IA: guarda reels que funcionan, aprende cómo hablas, te escribe guiones con tu voz y edita
tus videos. **Tú solo grabas.**

Esta es la plantilla. Para usarla necesitas un **código de SKIDUSH**, que llega con el reto de @aldushmedia.

## Instalación (una vez, unos 10 minutos)

1. Crea una cuenta gratis en [GitHub](https://github.com) y ten tu plan **Pro** de [Claude](https://claude.ai).
2. Arriba a la derecha de esta página: **Use this template › Create a new repository**. Ponle un nombre (por ejemplo
   `mi-skidush`) y elige **Private**.
3. Entra a [claude.ai/code](https://claude.ai/code), conecta GitHub y elige tu repo nuevo.
4. En el entorno (el menú del entorno arriba, después **Edit**), cambia **Network access** a **Full**.
5. Escribe «hola» y pega tu código cuando Claude te lo pida. Listo: empieza tu entrevista.

Tu código es personal: funciona en una sola cuenta de GitHub y vale hasta la fecha que te dimos.
